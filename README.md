## 📌 Sobre o projeto

A Calculadora de Consumo Elétrico é um programa desenvolvido em Python que permite estimar o consumo mensal de energia elétrica de um aparelho.

O usuário informa o nome do aparelho, sua potência em watts e o tempo médio de utilização diária. Com essas informações, o programa calcula o consumo estimado em kWh por mês.

O programa também apresenta uma estimativa do custo mensal utilizando o valor fixo de R$ 0,75 por kWh.

## 🎯 Objetivo

O objetivo do projeto é desenvolver um programa simples para auxiliar na estimativa do consumo de energia elétrica de aparelhos domésticos.

Além disso, o projeto permite aplicar conceitos de:

- Algoritmos;
- Programação estruturada;
- Entrada e saída de dados;
- Variáveis;
- Operações matemáticas;
- Estruturas condicionais.
